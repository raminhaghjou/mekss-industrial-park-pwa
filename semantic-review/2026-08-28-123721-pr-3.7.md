تست جدید دو park را ایجاد و دو `PUT` هم‌زمان را با `" UPDATE-RACE-WINNER "` و `"UPDATE-RACE-WINNER"` ارسال می‌کند (`mekss-backend/test/park-management.e2e-spec.ts:254-269`). statusها باید دقیقاً `[200, 409]` باشند و در پایان فقط یک row code مقصد را داشته باشد (`mekss-backend/test/park-management.e2e-spec.ts:270-279`). park بازنده با ID واقعی دوباره خوانده می‌شود و code اولیه‌اش باید باقی مانده باشد؛ audit نیز دقیقاً یک `PARK_UPDATED` برای winner و صفر برای loser است (`mekss-backend/test/park-management.e2e-spec.ts:277-283`).
